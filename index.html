Tools

Base labels use initials; duplicate names get numbered labels. Hover a base for its full name. Select an oval base and drag its yellow handle to rotate.

Range / measurement circles

Set a diameter or radius, then add a transparent circle to the battlefield. Drag it freely; select it and use Delete to remove it. Turn on Movement arrow trails to record translucent paths while dragging units.

Measurements are not snapped to the grid.

Import a list

Paste a simple list, one unit per line. Examples: 5 Liberators, Liberators x5.

Best-effort matching against the bundled base-size index.

Scale: The board is rendered from a 60" × 44" coordinate system. Every grid square is exactly 1" × 1"; unit bases and measurement circles use the same scale.

Map geometry: Deployment zones and fixed battlefield objects are encoded as editable vector geometry in data/battleplans.json. The PDF is not used as a background layer.

Battleplan/rules source: Wahapedia — General’s Handbook 2026–27. Map geometry is represented as game-board coordinates rather than a raster image.
